# AI実践アシスト

AI副業の実践記録と発信づくりを安全に支援するアプリです。
HTML / CSS / JavaScript だけで動き、記録はあなたのブラウザの中(localStorage)にだけ保存されます。

## できること

- **ホーム**:今日の収益・今週の作業時間・実践記録数などをひと目で確認
- **記録**:日々の実践(使ったAIツール・作業・学びなど)を保存、編集も可能
- **発信**:note記事用 / X投稿用 / X返信用のプロンプトを生成してコピー
- **履歴**:過去の記録をカードで一覧表示、詳細・編集・削除

## 安全方針

- 自動リプ・自動いいね・自動フォローの機能はありません
- ID・パスワード・Cookieは一切扱いません
- 「Xの投稿画面を開く」ボタンはXの公式投稿画面を開くだけです。投稿の最終確認と操作は必ず自分で行ってください
- 外部サービスやAPIは使っていません(通信はXの公式画面を開く1か所だけ)

## 使い方(いちばん簡単な方法)

`index.html` をダブルクリックすると、ブラウザでそのまま使えます。

## ホーム画面に追加する(PWAとしてインストール)

アプリとしてインストールするには、このフォルダを **http(s)で開く** 必要があります(スマホアプリと同じセキュリティ上のルールのためです)。

### パソコンで動かす場合(Pythonがある場合)

1. このフォルダでコマンドを実行:`python -m http.server 8765`
2. ブラウザで `http://localhost:8765` を開く

### 各端末でのインストール方法

- **iPhone(Safari)**:ページを開く → 共有ボタン(□に↑)→「ホーム画面に追加」
- **Android(Chrome)**:ページを開く → 右上のメニュー(⋮)→「ホーム画面に追加」または「アプリをインストール」
- **PC(Chrome / Edge)**:アドレスバー右端のインストールアイコン(画面に↓のマーク)をクリック →「インストール」

インストール後は、ホーム画面のアイコンから全画面(アプリ表示)で起動でき、オフラインでも基本画面が開けます。

### スマホから使いたい場合の注意

スマホのブラウザは、パソコンの中のファイル(file://)を直接開けません。
スマホでインストールして使うには、無料のホスティングサービス(例:GitHub Pages、Netlify)にこのフォルダを置いて、そのURLを開くのが確実です。
※Androidの「アプリをインストール」とオフライン機能は、https のサイトでのみ有効になります。

## データについて

- 記録はブラウザの localStorage に保存されます。**同じ端末・同じブラウザでのみ**引き継がれます
- ブラウザの履歴・サイトデータを削除すると記録も消えるのでご注意ください
- **バックアップ**:履歴画面の「データのバックアップ」から、全記録をJSONファイルとして書き出し・復元できます。機種変更やブラウザ変更の前に書き出しておきましょう
  - 復元は「既存に追加(重複はスキップ)」と「すべて置き換える」から選べます
  - 壊れたファイルや形式の違うファイルは読み込み前にチェックされ、既存の記録は守られます

### アプリを修正して再公開する手順

このフォルダでファイルを編集したあと、次の3つのコマンドを順に実行するだけです(1〜2分で公開に反映されます):

```
git add -A
git commit -m "変更内容をここに書く"
git push
```

- スマホにインストール済みの場合、アプリを何度か開き直すと新しいバージョンに切り替わります
- `service-worker.js` の先頭にあるバージョン名(例:`ai-jissen-assist-v2` → `v3`)を上げておくと、確実に更新が行き渡ります

## ファイル構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の骨組み(ホーム/記録/発信/履歴の4画面) |
| style.css | デザイン(青×白、スマホアプリ風) |
| script.js | 動き(保存・統計・プロンプト生成・コピーなど) |
| manifest.json | アプリ情報(名前・アイコン・テーマカラー) |
| service-worker.js | オフライン対応の仕組み |
| icon-192.png / icon-512.png | アプリアイコン |
